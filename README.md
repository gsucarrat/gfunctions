# gfunctions
glag() and gsummary(): Modified versions of lag() and summary()

# Installation
The following R command installs the stable version from CRAN:

    install.packages('gfunctions', dependencies = TRUE)

To install the current development version available here at Github, use the following command:

    install.packages(
      "https://github.com/gsucarrat/gfunctions/raw/refs/heads/main/gfunctions_devel.tar.gz",
      repos = NULL, type = "source"
    )
